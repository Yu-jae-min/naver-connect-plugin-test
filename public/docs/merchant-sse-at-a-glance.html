단말 3대 연결 예시

한 사업자의 단말 3대가 연결된 예시입니다. Vue2 데스크톱 브라우저는 SSE에 연결하지 않고 별도의 POST를 보냅니다.

  1. 1단말이 연결Next.js 단말기 브라우저 3대가 각각 EventSource로 GET 요청을 보냅니다. Next.js 서버는 응답 3개를 끝내지 않고 열어 둡니다.
  2. 2연결 등록Next.js 서버는 각 SSE 연결 전용 send()를 만들고, 해당 사업자의 clients 목록에 등록합니다.
  3. 3Vue2가 알림Vue2 데스크톱 브라우저가 토큰과 메시지를 POST합니다. Next.js 서버는 토큰으로 사업자 코드를 확인합니다.
  4. 4단말에 전달Next.js 서버는 해당 사업자의 send() 3개를 호출해 각 단말의 열린 SSE 응답에 메시지를 씁니다.

핵심: 단말 3대 = 열린 SSE 연결 3개 = 연결 전용 send() 3개. clients는 Next.js 서버가 사업자별로 보관하는 전송 함수 목록입니다.
